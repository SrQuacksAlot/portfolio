01 / About

I like the part where it has to work.

My work sits between backend logic and the interface people actually use. That can mean an API with clear boundaries, a data pipeline that stays predictable, or a game loop that feels right at 60 fps.

At KTH I focused on software development, with coursework in operating systems, computer networks, data storage, AI and application architecture. My projects range from a Spring Boot recruitment platform and a React route-planning app to a CARLA racing agent trained from scratch and a 3D tool for exploring how language models distribute probability.

Outside coursework I build games in Unity and Three.js. That is where I keep practising the parts that are hard to fake: state, timing, feedback and performance.
