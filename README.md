# Khalil Khalil — Portfolio

Personal portfolio: <https://srquacksalot.github.io/portfolio/>

A single-page site built with plain HTML, CSS and JavaScript. No build step and no framework.

## Structure

- `index.html` — page content
- `assets/css/style.css` — layout, theme and responsive styles
- `assets/js/main.js` — navigation, scroll reveal and email copy
- `assets/favicon.svg` — favicon

## Local preview

Open `index.html` directly, or run a static server from this folder:

```bash
python -m http.server 8080
```

Then visit <http://localhost:8080>.
